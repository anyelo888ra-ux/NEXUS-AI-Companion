# Roadmap

## 0.1 — basic companion
- [ ] Select and verify exact loader/Minecraft version combinations.
- [ ] Register a visible Nexus companion entity.
- [ ] Add `/nexus follow`, `/nexus stay`, `/nexus come`.
- [ ] Basic chat interaction.
- [ ] Client/server permission checks.
- [ ] Build and launch-test each supported loader separately.

## 0.2 — AI bridge
- [ ] Local bridge or secure server endpoint.
- [ ] Configurable API endpoint; no embedded keys.
- [ ] Chat responses with bounded context.
- [ ] Timeouts, rate limits and offline fallback.

## 0.3 — companion behavior
- [ ] Follow and look at player.
- [ ] Stay/come behavior.
- [ ] Optional voice output.
- [ ] Memory that the player can inspect and clear.

## 0.4 — advanced actions
- [ ] Assist with building only after explicit approval.
- [ ] Optional mining tasks with strict limits.
- [ ] Multiplayer protections and server-owner controls.
